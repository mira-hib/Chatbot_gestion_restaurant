🚀 DÉMARRAGE RAPIDE
═══════════════════════════════════════════════════════════════

   > quick_start.bat

Ou manuellement:
   $ python -m venv venv
   $ venv\Scripts\activate        # Windows

   $ pip install -r requirements.txt
   $ python manage.py migrate
   $ python manage.py shell < setup_initial_data.py
   $ python manage.py runserver
